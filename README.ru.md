# png-to-ico-windows

Пакетная конвертация изображений (`.png`, `.jpg`, `.jpeg`) в **ICO 256×256** с жестко прозрачным белым фоном для решения проблем с отображением в Windows и на USB-накопителях.

English version: [README.md](README.md).

## Зачем это нужно

Обычная конвертация часто приводит к появлению белых ореолов из-за мягких краев, проблемам с масштабированием из-за множества слоев внутри ICO и к устаревшему кэшу иконок в Windows.

## Что делает скрипт

- Поддерживает расширения `.png`, `.jpg`, `.jpeg`, `.jfif`, `.webp`, `.bmp`, `.gif`, `.tif`, `.tiff`.
- Создает один слой 256×256 в формате BMP внутри ICO для совместимости со старыми shell-API.
- Обрабатывает альфа-канал через LANCZOS с предумножением, оставляя значения только 0 или 255.
- Удаляет белый фон по краю, сохраняя внутренние белые детали (или всё белое при включении флага `--remove-all-white`).
- Проверяет полученный `.ico`-файл после сохранения.

## Требования

- Python 3.9+
- Pillow 10+
- Windows (для автоопределения папки `Downloads` и запуска через `.bat`; на других ОС требуется флаг `--input`).

## Установка

```bash
git clone https://github.com
cd png-to-ico-windows
python -m pip install -r requirements.txt
```

## Запуск

По умолчанию обрабатывает папку `Downloads` и сохраняет результат в `Downloads/new`:
```bash
python make_ico.py
```

Указание пользовательских папок и удаление всего белого цветов:
```bash
python make_ico.py --input ./source --output ./icons --remove-all-white
```

### Быстрый запуск на Windows (`run_ico.bat`)

- **Двойной клик** запускает обработку папки `Downloads` по умолчанию.
- **Drag-and-Drop** позволяет перетащить папку с изображениями или отдельный файл (`.png`, `.jpg`, `.jpeg`) прямо на значок `run_ico.bat`.

Автоматически проверяет и устанавливает Pillow, поддерживает настройку пути к портативному Python через переменную `PYTHON_EXE`.

### Параметры

| Параметр | По умолчанию | Описание |
| :--- | :--- | :--- |
| `--input DIR` | реальная `Downloads` | Папка с исходными изображениями (`.png`, `.jpg`, `.jpeg`). |
| `--output DIR` | `<input>/new` | Папка для сохранения готовых иконок. |
| `--threshold 0-255` | `235` | Порог определения белого цвета. |
| `--remove-all-white` | выкл. | Удаление всех близких к белому оттенков. |
| `--version` | — | Вывод версии скрипта. |
