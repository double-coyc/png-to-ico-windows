# png-to-ico-windows

Пакетная конвертация PNG/JPG/JPEG в **ICO 256×256** с жёстко прозрачным белым фоном. Рассчитано на случаи, когда Проводник Windows или иконка USB через `autorun.inf` показывает белый квадрат либо бледную полупрозрачную картинку.

English version: [README.md](README.md).

## Зачем это нужно

Обычная конвертация в ICO не решает три проблемы:

1. **Мягкие края, смешанные с белым.** После вырезания фона остаются полупрозрачные пиксели; Windows рисует их как белый ореол или делает иконку бледной.
2. **Несколько слоёв в ICO.** В файле могут лежать 16×16, 32×32, 48×48 и 256×256. Windows может взять мелкий слой с артефактами ресайза.
3. **Кеш иконок.** Windows долго показывает старую версию, пока файл не переименован или кеш не сброшен.

Скрипт решает первые две проблемы; для третьей ниже есть инструкция.

## Что делает скрипт

- Пишет ровно **один слой 256×256** (`sizes=[(256, 256)]`).
- Сохраняет слой как **BMP внутри ICO** (`bitmap_format="bmp"`), а не PNG. Современный Проводник обычно читает и PNG-слой, но часть старых shell-API, используемых для `autorun.inf`, — нет. Минус BMP: файл больше, около 256 КБ на иконку.
- После ресайза ставит альфу строго **0 или 255**. Полупрозрачных пикселей нет, поэтому иконка не выглядит бледной.
- Ресайзит через **LANCZOS с предумноженной альфой**, чтобы края не смешивались с белым и не давали белый ореол.
- Удаляет белый **только там, где он соединён с краем картинки**. Белые детали внутри рисунка (например, полоски сервера) остаются непрозрачными. Флаг `--remove-all-white` удаляет весь почти-белый цвет.
- После сохранения заново открывает ICO и проверяет количество слоёв, размер, BMP-кодирование и альфу.

## Требования

- Python 3.9+
- Pillow 10+
- Windows — для автоматического определения папки Downloads. На других системах укажите `--input`.

## Установка

```bash
git clone https://github.com/Double-Coyc/png-to-ico-windows.git
cd png-to-ico-windows
python -m pip install -r requirements.txt
```

## Запуск

```bash
python make_ico.py
```

По умолчанию скрипт берёт файлы из **реальной** папки Downloads и пишет в `Downloads/new`. На Windows путь читается из реестра, поэтому перенесённая папка (например, `D:\Users\name\Downloads`) тоже работает.

Свои папки:

```bash
python make_ico.py --input ./source --output ./icons
```

Удалить весь почти-белый цвет, включая белые детали внутри рисунка:

```bash
python make_ico.py --remove-all-white
```

### Параметры

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `--input DIR` | реальная Downloads | Папка с PNG/JPG/JPEG (без вложенных папок). |
| `--output DIR` | `<input>/new` | Папка результата; создаётся при необходимости. |
| `--threshold 0-255` | `235` | Пиксель считается белым, если R, G и B больше порога. |
| `--remove-all-white` | выкл. | Удалять весь почти-белый цвет, а не только фон, соединённый с краем. |
| `--version` | | Показать версию. |

Имя результата совпадает с исходным: `photo.jpg` → `photo.ico`.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты создают картинку с белым фоном, цветной рамкой и замкнутой белой дырой и проверяют, что:

- в ICO ровно один слой 256×256;
- фон прозрачный;
- замкнутая белая область по умолчанию остаётся непрозрачной;
- с `--remove-all-white` она становится прозрачной;
- CLI создаёт файл в указанной папке.

CI запускает тесты на Windows и Linux с Python 3.10 и 3.12.

## Иконки на USB-флешке

1. Скопируйте новые `.ico` на флешку.
2. Переименуйте их на флешке (например, добавьте `_v2`), чтобы Windows не взяла старую версию из кеша.
3. Обновите `autorun.inf`:

   ```ini
   [autorun]
   icon=images_v2.ico
   label=My USB
   ```

4. Сбросьте кеш иконок: `Win+R` → `cmd` → `ie4uinit.exe -ClearIconCache`.
5. Перезапустите Проводник: Диспетчер задач → «Проводник» → «Перезапустить».
6. Безопасно извлеките флешку и вставьте обратно.
